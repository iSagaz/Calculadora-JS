# 🧮 Calculadora JavaScript

Uma calculadora desenvolvida utilizando **HTML, CSS e JavaScript**, com o objetivo de praticar lógica de programação, manipulação do DOM e eventos em JavaScript.

## 🚀 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## ⚙️ Funcionalidades

- Adição, subtração, multiplicação e divisão.
- Interface interativa com botões para cada operação.
- Captura e conversão de valores numéricos utilizando `Number()`.
- Manipulação de elementos HTML com JavaScript.
- Tratamento de divisão por zero.

## 📚 Objetivo do projeto

Este projeto faz parte dos meus estudos de JavaScript e tem como propósito desenvolver habilidades práticas na construção de aplicações web, trabalhando conceitos fundamentais da linguagem.
